Javascript Fundamentals

An analogy to describe JavaScript and its relationship to HTML and CSS.

HTML and CSS are respectively the ‘builder’ and the ‘artist’ of a page/website. JavaScript is the ‘wizard’ that comes along and provides the page/website with interactivity. Javascript is the wiring behind the switches.

Explain control flow and loops using an example process from everyday life, for example, 'waking up' or 'brushing your teeth' (but not those).

Control flow refers to the order in which Javascript executes a programme. Code is run in order from the first line at the top of a script to the last line, unless the computer runs across structures that change the control flow, such as loops. A loop is a sequence of instructions that is continually repeated until a certain condition is met. An analogy for control flow is writing down a to-do list for the day, in the order that you will carry out the tasks throughout the day. A loop, then, is similar to carrying out a task repetitively until a particular condition is met before you can move onto the next task.

Describe what the DOM is and an example of how you might interact with it.

DOM is short for ‘document object model’. It's an object representation of the entire html document and can be shown as a 'tree'. It acts as the gateway to all the content going on in your page and is the glue that glues HTML, CSS and JavaScript together. Everything that makes up the DOM is known as a node (eg, elements, attributes, text content, comments).

Every html element that you use, has a JavaScript equivalent representation and you can access these and modify things. Any change you make to the DOM via JavaScript is reflected in what gets shown in the browser. This means you can dynamically add elements, remove them, move them around, modify attributes on them, as well as set inline CSS styles

Explain the difference between accessing data from arrays and objects.

An array is a special variable which can hold more than one value at a time. It is a list-like structure that consists of an ordered collection of elements, each identified by an index number (starting with ‘0’). Arrays are declared using square brackets [ ] on JavaScript. The key difference between Arrays and Objects is how the data is organized. Arrays are used when we need to collect a list of elements of the same data type or structure. They are useful for storing data where the order of elements matters. objects are used when grouping multiple sets of data that belong together using labels, where each property or key has its own value of any type. Organizing data in key-value pairs makes for easy retrieval and manipulation.

Explain what functions are and why they are helpful.

A function is a reusable block of code that performs a specific task. It takes input(s) as parameters, performs some operations on them and returns a result. In simpler terms, it is like a recipe. A recipe tell you what ingredients you need and what steps to follow to make something. A function therefore, tells a computer what to do and how to do it.
